# 《荣格心理学入门》解读系列 — 写作规范

本系列基于 ljg-xray-book「深度拆书」思想（Epiplexity 原理：投入认知算力，把"噪声"变成"可学习的结构"）。

## 每篇文章必须包含（融入行文，不是干巴巴的表格）

1. **餐巾纸开场**：文章开头用一个"一句话 + 一个公式/一张 ASCII 图"把本章精华压缩到极限，让读者 30 秒抓住核心。
2. **骨架**（这章在说什么）：核心问题 → 核心答案 → 概念地图。
3. **血肉**（凭什么这么说）：还原河合隼雄的论证链条；必须使用书中真实的案例/证据（如安娜喝水案例、词语联想测验、"肉的漩涡"之梦、宾馆杀人梦、印刷厂老板破产案例等），不许编造书里没有的案例。
4. **灵魂**（还能怎么用）：
   - 隐形假设：作者没说但必须成立的前提
   - 边界条件：这个理论何时失效、何处存疑（用现代心理学视角诚实批判，如荣格理论的可证伪性问题、MBTI 对类型论的滥用等）
   - 跨域映射：这个思想在其他领域叫什么
   - 行动触发：读完这章，读者今天就能做的一件不同的事
5. **与全书的连接**：说明本章概念在荣格体系中的位置（无意识分层地图上的坐标），并预告与下一章的逻辑衔接。

## 文风要求

- 面向没读过原书的聪明读者；读完文章 = 吸收该章全部精华，且比自己读原书理解更深。
- 中文写作，专业术语首次出现附英文原文。
- 用小标题分节；ASCII 图只用基础符号 (+, -, |, >, <, /, \, *, =, .)。
- 长度不设上限，以"完整吸取精华"为准，通常 3000-6000 字。
- 语言鲜活，避免教材腔；可以直接引用书中金句（引用要准确）。
- 诚实：河合隼雄自己承认"讲不清楚"的地方（如原型、阿尼姆斯），要如实呈现这种"讲不清楚"本身的意义。
