# 08 · 阿尼玛与阿尼姆斯：内心的异性，与人格面具的代价

## 餐巾纸开场

一句话：**你对外扮演得越"像个男人/像个女人"，你内心就积攒着一个越强大的异性——不认识它，它就在背后操纵你；认识它，它就成为通往完整人格的桥。**

```
          外部世界                     内部世界
             |                            |
   +------------------+        +--------------------+
   |  人格面具 persona |  <-互补->  |  阿尼玛 / 阿尼姆斯  |
   |  (对外的面具)     |        |  (对内的态度/心灵)  |
   +------------------+        +--------------------+
             |                            |
     过度同化 = 僵化的小丑面具      过度同化 = "像变了一个人"
             \                          /
              \______ 分化并整合 ______/
                        |
                        v
                  更完整的人格
```

公式化地说：**梦中同性形象 = 阴影；梦中异性形象 = 阿尼玛（男性梦中的女性）/ 阿尼姆斯（女性梦中的男性）**。阴影是"我不愿承认的我"，阿尼玛/阿尼姆斯则埋得更深——它是"我从未活过的另一半"。

## 骨架：这章在说什么

核心问题：一个人把外部适应做到满分之后，为什么还会生病？内心那个与外表完全相反的部分，到底是什么、要怎么对待？

核心答案：荣格认为人需要两种根本态度——对外的态度凝结为**人格面具（persona）**，对内的态度凝结为**阿尼玛（anima）**（对女性而言是**阿尼姆斯（animus）**）。两者互补：外部越强悍，内心越柔弱；外部越柔顺，内心越刚硬。这个内在的"异性"以意象形式出现在梦中，它既可能诱人堕落，也可能召唤出创造力；既不能压抑，也不能被它同化，唯一的正路是**分化开来看清各自面目，然后艰难地整合**。

概念地图：本章先用人格面具做参照基准（第1节），再分别展开男性的阿尼玛及其四阶段发展（第2节）、女性的阿尼姆斯及其四阶段发展（第3节），最后指向"阿尼玛/阿尼姆斯作为连接自我与自性的机能"——这是下一章"自性"的入口。

还有一个不可忽略的细节：河合隼雄在本章开头就坦白，"写这一章，我也感到非常难以下笔，或许只能谈及一些皮相的内容"。一位职业分析家在自己的专著里承认写不好某一章——这句话本身就是本章最值得解读的材料之一。我们最后会回到它。

## 血肉：凭什么这么说

### 1. "适应得太好"也是病：人格面具的代价

荣格区分了两个词：**psyche** 指全部心理过程（意识加无意识），而 **soul** 指对内心过程的根本态度。河合隼雄为了避开宗教味的"灵魂"二字，学夏目漱石用平假名"こころ"来译 soul。这个翻译上的小心翼翼提示我们：阿尼玛不是什么神秘实体，而是"你如何对待自己内心"这件事的原型化表达。

人为什么需要人格面具？因为外部环境无时无刻不在提出要求：父亲要有父亲的样子，教师必须为人师表。做不到，立刻被贴上"适应能力差"的标签。但河合隼雄用一个亲历的案例指出，还有一种更隐蔽的病——**对自己内部的不适应**。

他在美国留学时，有一位日本留学生跟当地美国人处得极好：朋友是美国人，导师给好评，连女朋友都是美国人——在当年的日本留学生里是罕见的模范适应者。可这个人找不到原因地慢性拉肚子。美国医生断定是神经性的，却在他身上找不到任何"不适应"的迹象，满头雾水。河合隼雄更吃惊的是，还有情况类似的留学生主诉慢性消化不良。诊断由此翻转：**他们的"不适应"恰恰来源于对外部世界过于完美的"适应"**——把全部能量投入表面适应剧变的美国文化，疏忽了自己的内心活动，于是身体替内心报了警。

这就是本章的枢纽命题：人在无法适应外部时会得神经症，在忽视内心调整时同样会得神经症。对外的合适态度是人格面具，对内的合适态度就是阿尼玛（心灵）。

人格面具在梦中很少人格化，通常表现为**衣服**。书中举了一位未婚职业女性的梦：她坐着，拿伞和棍子把好几个男人挨个打得掉进河里，正要以必胜姿态站起来迎战最后一人时，突然发现自己赤身裸体，羞得稀里糊涂又坐了回去，说"不管怎样至少先穿上衣服吧"。现实中，这位女性工作能力很强，却克制不住地说出不必说的话，招上司讨厌；工作太卖力，招同事嫉恨。剥去伪装、赤心相对本是好事，但也要看场合和时机——梦在告诉她：你缺一件合身的"衣服"，哪怕穿件泳衣也比赤裸着好。

人格面具的反面危险是**同化**。河合隼雄看过马歇·马叟的哑剧：一个男人试戴各种面具玩得兴起，小丑面具却怎么也拿不下来。身体在痛苦挣扎，脸上却保持着滑稽可笑的表情——两种完全对立的东西同时呈现，活生生演出了僵化人格面具的悲剧。军人、警官、乘务员的制服是防卫，但把人从头到脚包起来的制服，也会让人疑惑里边到底还是不是一个活生生的人。

而同化的另一端同样危险：日常很坚强严厉的男性被浅薄的同情心操纵干出傻事，一直很可爱的主妇突然受报上名人意见影响对客人滔滔演说——"怎么像变了一个人一样？"确实是这种感觉：一个男性的背后有位女性在活动，一位女性的身体当中走出来一个男性。

### 2. 阿尼玛：救起海底的少女

一位年轻单身男性在决定接受分析治疗后马上做了这个初始梦：他并不想去海水浴，但心里明白不得不去；别人游泳时只有他一人远离大家；突然，从海底浮上来一个裸体少女，他慌忙做人工呼吸，感到她的一丝呼吸后终于放心；然后回家给她找保暖的衣服——一堆衣服每一件都太小，没法穿。

这个梦几乎是一张阿尼玛概念的示意图。海是无意识本身；孤身一人是异常体验的开端（童话主人公总在迷失森林、被抛弃后遭遇奇迹）；濒死的少女是被意识长期拒绝、沉底在无意识里的"心灵"；人工呼吸恢复了心灵与自我的联系——而且，阿尼玛、阿尼姆斯的词源都来自希腊语 anemos（风），"灵魂"与"呼吸"本就相通。最妙的是结尾：日常的人格面具（衣服）**太小，装不下自己的内心**——这正是第1节命题的梦境版。

阿尼玛与劣势机能相结合：思维型男性的阿尼玛与情感机能结合，它未必以女性形象出现，也可以是梦中的"笛声"，或"天鹅少女"那样的动物形象——天鹅少女的故事在世界范围广泛分布、版本繁多却打动所有人，这正是阿尼玛扎根于集体无意识的证据。

阿尼玛向外投射时最戏剧化：有女性说一句"我相信你"，就成为男性创造力的源泉；反过来，女性一个轻蔑的眼神也能把成功者打入万丈深渊。荣格特别强调**人生后半的意义**：年过四十、一切开始走下坡路时，男性才意识到内心世界的存在，于是把"永远的女性"投射到现实中——非常古板的学者型男性被娼妓型女性搞得神魂颠倒，唐·璜一样的男性突然向清纯少女宣言矢志不移的爱。表面荒唐，但慧眼者能在愚蠢透顶的恋情下看到发展的可能：在与阿尼玛搏斗的过程中，男性可能走向更高统合性的人格。

荣格从大量案例中归纳出阿尼玛发展的四阶段——**生物学阶段、浪漫阶段、精神（spiritual）阶段、睿智（wisdom）阶段**——且很难跳级。起点甚至在阿尼玛之前：母亲形象。母亲的温暖、甜蜜与"永远把孩子据为己有"的吞没特性（devouring quality）都被阿尼玛意象继承；离不开母亲怀抱的男性中多有浅薄滥情的唐·璜型——在异性中寻求母爱，得不到满足就一个接一个更换对象，甚至"心理上被母亲抱在怀里，却有着征服众多女性的错觉"。过渡阶段是代理母亲："一直对我很温和的邻居小阿姨""第一次来访的亲戚家的表姐"——既是母亲形象的延长，也是"家"外魅力的初次显现。

四阶段各有典型意象：生物阶段是孕育一切的"土地"，强调性的一面时甚至以娼妓形象出现（看上去非常正经严肃的人在分析中出现娼妓型意象，总会大吃一惊）；浪漫阶段开始对某一个特定女性产生爱、认可其人格；精神阶段的典型是圣母玛利亚，性升华为神圣的爱；睿智阶段的典型是全身盔甲从宙斯脑袋里诞生的雅典娜——而河合隼雄补充了一个东方例子：中宫寺的弥勒菩萨像。人们在其中感受到的慈悲不同于圣母之爱，其魅力也无法与维纳斯相比，打动我们的是其中蕴含的深深智慧；有人甚至从菩萨面容上看到蒙娜丽莎式的微笑。有趣的对比是：**第三阶段的圣母式意象在日本基本没有发展，第四阶段日本反倒比西方更丰富。**

河合隼雄对日本的分析相当锋利：自古以来，日本为了守护"家"这个组织，极力压抑了阿尼玛的成长——女性的意义被限制在为家族孕育继承人的"土地"功能上，人格难以得到社会承认；作为替代品，江户艺伎承担了在阿尼玛意象中追求感官美的使命。即使在现代，能开发出浪漫阶段阿尼玛的日本男性仍少之又少；那些被称为女权主义者、浪漫主义者的男性，大部分还停留在代理母亲阶段，"下不了决心跟'娼妓型'阿尼玛面对面地决斗"——这刚好对应他们身上"没主见"的特性。

阿尼玛未必投射到人身上。在美国，家里的车经常起着阿尼玛的作用：男性较着劲买好车，像宝贝一样充满爱心地照顾它，喜滋滋地跟朋友谈论它——"比起男性化的美国女性，车好像更接近阿尼玛的意象。在近代合理主义主流思想的统治下，非合理的感情找不到投射的对象，想想也蛮可怜的。"

整合阿尼玛为什么重要？因为它强迫男性开发自己的薄弱环节：再逞强的人一旦陷入恋爱马上变得软弱、愚蠢——**正是因为内心真正经历了"软弱"的体验，男性才能够跟他人建立起货真价实的关系**。表面强大的男性有力量支配别人、命令别人，却没有能力在心灵深层与人对等交往。但要严格区分"整合阿尼玛"与"被阿尼玛同化"：后者只是无意义的娘娘腔、简单感情化、陷入感伤不能面对现实——河合隼雄毫不客气地点名，有些男性心理咨询师"总是散发出一种甜蜜的温柔气息"，正面临这种危险。

时机也有讲究：一般男性应在前半生先构建人格面具，后半生（三十五至四十岁以后）再与阿尼玛对决；还没建立起人格面具就与阿尼玛开战的人，"真有一种腹背受敌的感觉"。例外是艺术家、宗教家和心理治疗师——年轻时就不得不应对阿尼玛，算是一种宿命。

### 3. 阿尼姆斯：观点之剑与普绪喀的灯

女性对外温柔顺从，无意识里则积累着逻辑性和力量，人格化为梦中的男性形象。荣格有一个精辟对比：**阿尼姆斯形成观点（opinion），阿尼玛酝酿情绪**。被阿尼姆斯绑架的女性张口就是"你应该如何如何"——作为一般原理无疑正确，却在特定场面显得那么不协调；与之感情化争论的男性则被阿尼玛操纵，于是各说各的，永远两条平行线，只能等时间解决。

爱玛·荣格（荣格夫人）把阿尼姆斯的发展也分为四阶段：**力量、行为、语言、意义**——灵感来自《浮士德》中浮士德翻译希腊语 Logos 时发现其中含有言语（das Wort）、意义（der Sinn）、力量（die Kraft）与行为（die Tat）多重含义。力量阶段以体育健将等肉体强者形象出现；行为阶段是坚强意志支持下勇敢行动的男性，海明威是典型，"所以成为很多女大学生崇拜的对象"；对现代女性真正重要的是语言与意义两个阶段——理性原理的领地。

阿尼姆斯的消极面像一把剑。它的特性是锐利的斩断：明确认识差异、做出对错判断，快刀斩乱麻。但"现代的女性，看上去像是用阿尼姆斯之剑和男性在对等地拼杀，实际上却在不知不觉中把自己的女性生命（femininity）剁得稀巴烂"。而且在女性执着的观点背后，往往能找到父亲传下来的家训或报纸文章的观点——观点是借来的，执着是自己的。格林童话《画眉嘴国王》里的公主是标本：给所有求婚者起外号嘲笑、统统拒之门外，过后又几次后悔"我要是跟那个画眉嘴国王结婚就好了"——先用观点斩断一切，再用悔恨反噬自己（"我应该去上大学的""当初跟那个人结婚就好了"）。

积极面同样真实：当男性被僵化的条条框框束缚、极力阻挡社会变革时，往往有女性能发现变革的意义，挺身担当革新使命——勇敢藏匿被敌方追捕的志士的女性，正是建设性阿尼姆斯的例子。

阿尼姆斯无处安放时会转向。有的女性把它融进育儿家务，高效合理、乐在其中，但效率提高加上生育控制普及，主妇精力过剩；这些能量与低水准阿尼姆斯结合，或走向凄惨的性冒险（"试图依赖肉体的结合来体验心灵的分离"），更常见的是一股脑灌注到孩子身上——"要是和画眉嘴国王结婚就好了"的叹息逐日转化为对孩子的期待，孩子不得不为母亲的阿尼姆斯而活，于是诞生出"教育妈妈"。而河合隼雄把镜头转向旁边冷笑的丈夫："很多情况下可能依然是个'坐在妈妈的膝盖上'的假男人，还没长大。他一点都没有察觉到，正是自己成为妻子在阿尼姆斯发展道路上的障碍，才逼得自己的妻子不得不变成病态的'教育妈妈'。"夫妇关系里，"仅仅一方特别坏的情况真是不多"。

那么，不觉醒不就好了？希腊神话给出了残酷的回答。丘比特与普绪喀（Psyche）幸福地生活着，唯一条件是普绪喀不能看丈夫的样子。终于敌不过好奇心和疑虑，她夜里点灯偷看，丘比特发怒离去，普绪喀从此踏上苦难历程——克服重重艰难后才与丈夫重聚。寓意是：**只要没有意识到阿尼姆斯问题，女性可以一直过着单纯甜蜜的幸福生活；但内心一旦产生了什么，就再也回不去了**——"女性一旦察觉到阿尼姆斯的存在，再让她回归无知是不可能的"，剩下的唯一出路是像普绪喀那样把苦路走到底。现实中也确有从未觉醒的女性：没有个性，恰恰最适合承接男性的阿尼玛投射，"同性看来无聊透顶的一个人，却很吸引异性"。河合隼雄的态度极有分寸："真不忍心刻意去唤醒看不见阿尼姆斯的那些人，但对于那些已经觉醒的人们，必要的时候我们应该尽全力给予帮助。"

最后一个理论疑难：为什么描写阿尼玛的文学作品林林总总，描写阿尼姆斯的却很少？荣格自己坦言："我找不到一个例子能够很清晰地表达女性的阿尼姆斯人格。"阿尼玛往往以**一个**女性形象出现，阿尼姆斯却经常牵扯到二、三人甚至更多男性（一人对打多个男人的梦即是例子）——阿尼姆斯似乎是**复数人格**。爱玛·荣格的解释颇有启发：自古以来女性最重要的角色是母亲，所以对男性来说所有女性意象都脱胎于母亲，阿尼玛形象单纯统一；而男性不仅是父亲，还有复杂的职业身份，女性的阿尼姆斯受各种男性形象影响，很难凝成一个独立人格。

## 解读点：河合隼雄的"难以下笔"本身在说什么

本章开头，河合隼雄写下了全书罕见的一段自白：从他"依然非常贫乏"的经验来看，"对日本人来说，整合自己的阿尼玛和阿尼姆斯比起西洋人要困难很多。因此，写这一章，我也感到非常难以下笔，或许只能谈及一些皮相的内容"。章末他又补一刀：荣格的四阶段"是不是就可以囫囵吞枣地应用到日本人身上呢，这还是一个需要探索的大问题"。

这段坦白至少有三层意义。

第一层，它是**方法论的诚实**。荣格心理学的知识来源是临床经验的归纳，不是逻辑演绎。荣格的四阶段总结自欧洲人的梦，河合隼雄在日本的诊疗室里发现对不上号——一个诚实的经验主义者只能承认：我的样本不支持直接套用。他没有假装体系完备，这恰恰是这套"不科学"的学问最科学的时刻。

第二层，它本身就是一份**文化诊断书**。为什么日本人整合阿尼玛更难？他自己在正文里给出了答案：守护"家"的制度压抑了阿尼玛的成长，"土地"般的母性力量覆盖全家族，"使得多数日本男性永久无法逃出大地一样的母亲的势力范围"。也就是说，"难以下笔"不是作者个人的笔力问题，而是他所属文化的集体课题——**连分析家本人也身在其中**。一个日本分析家写不好阿尼玛这一章，恰如一个男人说不清自己的阿尼玛：说不清的地方，正是问题最深的地方。

第三层，它是**对读者的示范**。整章都在讲"承认自己的薄弱环节"——男性要经由阿尼玛体验软弱，女性要经由阿尼姆斯之路穿越苦难。河合隼雄用"我写不好"完成了同样的动作：把自己的劣势机能暴露在读者面前。这比任何说教都更有力地演示了"不与人格面具同化"是什么样子——一个作者的人格面具是"无所不知的专家"，他摘下来了。

## 灵魂：还能怎么用

### 隐形假设

这套理论要成立，至少需要几个未言明的前提：(1) 社会对两性的期待是高度定型的——男性被期待强壮和判断力，女性被期待温和柔顺，人格面具才会沿性别轴线分裂出一个"异性"的内在补偿；(2) 梦中人物的性别携带稳定的象征意义（同性=阴影，异性=阿尼玛/阿尼姆斯）；(3) 心理发展有方向性和阶段性，且"很难跳跃过某个阶段"。这三条中任何一条松动，理论都需要改写。

### 边界条件：当代性别观念下的再审视

这是本章绕不开的坎，而且必须诚实地说：**阿尼玛/阿尼姆斯是荣格体系中受当代性别研究冲击最大的概念。**

问题出在哪里？荣格的原始表述把"逻辑、力量、观点"划给男性原理，把"情感、和谐、情绪"划给女性原理，再让每个人内含异性的那一半。这在他的时代是激进的——它承认男人内心有女性、女人内心有男性，打破了"男人就该百分百男人"的铁板。但用今天的眼光看，这个框架把一组**社会建构的特质**（理性/感性、强/弱、观点/情绪）先天化、性别化了：为什么"形成观点"是男性的？为什么"酝酿情绪"是女性的？本章里那些年代感强烈的表述——被阿尼姆斯附体的女性"没有一点女人味儿"、男咨询师"娘娘腔"的危险——今天读来刺眼，因为它们默认了一套固定的性别脚本。

更结构性的困难是：这套理论以异性恋的二元框架为轴。一个同性恋男性的"内在异性像"如何运作？一个非二元性别者的人格面具沿什么轴线分裂？荣格没有回答，本章也没有。理论在这些人群面前不是"错"，而是**沉默**——它的解释范围比它自己以为的要窄。

但这不等于概念作废。有一条可行的再解释路径：把阿尼玛/阿尼姆斯**去性别化**，还原为它的功能内核——**"被人格面具排斥掉的那一面形成了内心世界的本质内容"**。这句话本身不依赖性别：任何人为了社会适应而压抑的特质，都会在内心积累成一个补偿性的"他者"，并在梦中人格化为与自我形象反差最大的形象。在性别脚本严格的社会里，这个"反差最大的形象"自然是异性；在性别脚本松动的社会里，它可能沿别的轴线取形。这样一来，理论的核心洞察（面具与心灵的互补、被排斥者的人格化、整合而非同化）得以保留，而它的十九世纪性别外衣可以脱下。事实上，河合隼雄自己已经示范了这种灵活性：他明确说阿尼玛"并不绝对以女性的形象出现"，可以是笛声、天鹅、甚至美国男人的汽车——概念的锚点从来是**功能**（对内的态度、劣势机能的载体），不是生理性别。

还要提防另一个方向的滥用：把"男人要开发女性面、女人要开发男性面"变成新的鸡汤指标。荣格的阶段论建立在个案归纳上，没有可证伪的预测；四阶段的划分（娼妓—浪漫—圣母—雅典娜）带着浓重的欧洲文化印记，河合隼雄已经示范了它在日本水土不服。任何把它当作普适发展量表来测评他人的用法，都背离了它作为**临床解释工具**的本分。

### 跨域映射

- 社会学里，戈夫曼的"拟剧论"（前台/后台）与人格面具几乎同构：前台表演越用力，后台积压越多——那位拉肚子的留学生就是前台表演满分、后台失修的案例。
- 性别研究中，"异性特质的补偿"接近于对性别脚本（gender script）压抑成本的分析：社会规定你不许表现什么，那个"什么"不会消失，只会转入地下。
- 组织行为学里的"角色吞噬"（role engulfment）对应人格面具同化：制服里"到底还是不是一个活生生的人"。
- 文学批评中，"缪斯"传统正是阿尼玛投射的制度化——而女性作家"要告诉男性，真实的女性不是你们投射的那样"，则是对这一投射的集体反击。

### 行动触发

今天做一件事：找出你的"制服"。问自己——我在什么场合的表现最无懈可击、最受好评？然后问第二个问题：**为了维持这个表现，我按下不表的是什么？**如果你想不出答案，留意接下来一周里两类信号：一是身体的（那位留学生的肠胃比他的意识诚实），二是你对某类人莫名强烈的情绪反应（被投射的阿尼玛/阿尼姆斯，往往就挂在那个让你"神魂颠倒"或"敬而远之"的人身上）。不需要立刻改变什么——本章的教导恰恰是：先分化、看清，再谈整合；在建好面具之前拆面具，是腹背受敌。

## 与全书的连接

在荣格的无意识分层地图上，本章走到了倒数第二层。情结（第四章）盘踞在个人无意识；阴影（第五章）横跨个人与集体无意识的交界，以同性形象现身，是"比较容易理解"的那一个；而阿尼玛/阿尼姆斯"存在于无意识的深处"，以异性形象现身，是集体无意识中比阴影更深的原型。梦的分析（第七章）提供了观测它们的仪器——上一章末尾那个"陌生女性"的梦，正是本章的引子。

而本章自己也留下了一个钩子：荣格说，经过四个阶段的发展，阿尼玛将不再以人格化形式出现，而是作为一个机能（function），**把自我与心灵真正的中心"自性"联系起来**。阿尼玛/阿尼姆斯原来不是终点，而是摆渡人。那么，渡到的彼岸——那个通过它才能建立关系的"自性"究竟是什么？男女走过各自的苦路、在人格中包容强弱两面之后的"个性化过程"又如何展开？这就是下一章、也是全书压轴的主题：自性与个性化，一生的功课。
