# 09 · 自性与个性化：一生的功课

## 餐巾纸开场

一句话：**你以为"我"（自我）就是你的全部，其实它只是一个更大整体（自性）里的小圆——人生的终极功课，是让小圆学会与大圆对话，既不吞没对方，也不被对方吞没。**

```
        +---------------------------------+
        |                                 |
        |      自性 Self（大圆）           |
        |   意识 + 无意识的整体中心         |
        |                                 |
        |         +-----------+           |
        |         |  自我 ego  |           |
        |         |  (小圆)    |           |
        |         | 意识的中心  |           |
        |         +-----------+           |
        |                                 |
        +---------------------------------+

  自我吞掉自性 = 失去人生意义（"适应得太好而苦恼"）
  自性吞掉自我 = 妄想、自我膨胀（落水的瑜伽修行者）
  两者对决又协作 = 个性化（一生走不完的过程）
```

荣格的原话是这套关系最好的注脚："自性既是心灵的整体性，又是心灵整体的中心。自性不等同于自我，就像一个大的圆包含着小圆一样，自性包含着自我。"

## 骨架：这章在说什么

核心问题：人格已经稳定、社会已经承认、事业已经成功——为什么还是有人在某一天突然发现"从这些东西里再也找不到意义"？人心里那股不肯安分、总要打破稳定的力量，究竟从哪来，要往哪去？

核心答案：因为**自我（ego）只是意识的中心，而不是心灵整体的中心**。整体的中心是**自性（Self）**——整合意识与无意识、男性与女性、思维与情感等一切对立要素的功能中枢。它超出自我的感知范围，却持续推动人格向更高层次的统合前进。这个"实现个人内心世界存在的可能性，将自我提升到更高层次统合状态的努力过程"，荣格称为**个性化（individuation）过程**，或**自性实现（self-realization）**，并认为它是人生的终极目标——心理治疗的目的，也不外乎于此。

概念地图：本章是全书的收束点。前八章的所有概念——类型的两极、情结、阴影、人格面具、阿尼玛与阿尼姆斯——在这里全部归位：它们都是对立要素，而自性是让这些对立走向统合的中心。河合隼雄分三步展开：个性化的过程（自我与自性的关系及其危险）、自性的象征性表现（智慧老人、圣童、曼荼罗与"四"）、自性实现中的"时间"（kairos 与共时性）。

要先立一块警示牌：这一章绝不是"自我实现"鸡汤。河合隼雄明确批评，美国人看待自性实现"只盯着光明的一面而忽视了荣格提到的很多阴暗部分，有些盲目乐观的倾向"。荣格版的自性实现，一半篇幅在讲它有多危险。

## 血肉：凭什么这么说

### 1. 那股拆家的力量：从蜗牛出走说起

还记得第六章那组幼儿园女孩的画吗？蜗牛在家里住得好好的，画面中却渐渐显出"一种要把两者强行拉开的力量在暗中涌动"。河合隼雄追问：小女孩在家里住得舒舒服服，一直这样住下去不是很好吗？**但就是有一种内在的力量要破坏这种稳定状态，并试图以此为起点达到一个更高水平的统合状态。**

关键在于：这个过程发生时，女孩的意识毫无紧迫感——她甚至要冒着被调皮男孩欺负、被说"最近很嚣张"的风险。也就是说，推动变化的力量**超出了自我的范畴**。荣格认为，在意识领域之外存在着一个更高的整合中心，那就是自性。

这个思想的萌芽早在 1902 年荣格的博士论文里就有了。当时人们研究双重人格、梦游，都是从病理出发；弗洛伊德把它们还原为无意识里性的动因，而荣格从中读出了**目的的意义（teleological significances）**——新的人格发展的可能性受阻，才以意识障碍的形式表现出来。这是两人最显著的分岔之一：一个向后找原因，一个向前找目的。

河合隼雄用自己的一个案例把这层意思讲透了。一位因同性恋和梦游而苦恼的瑞士高中男生来做心理治疗，谈到同性恋对象时，当事人突然喊了起来："啊，这么看来，他就是我呀！在我的内心，希望自己这样，希望自己那样，希望的样子就是他呀！"——沉浸于同性之爱、睡着后梦游去见对方，表面看是异常行为；但从自性的视角看，这是**一种不惜采取异常行为也要弥补人格中欠缺部分、以达到更进一步统合状态的艰苦努力**。治疗的目的不是消灭这个行为，而是与当事人一起，把行为指向的潜在可能性整合进自我。从这个观点看，同性恋现象反而成了这位高中生走上自性实现之路的起点。

### 2. 东方的启发与荣格的保留：大圆与小圆

自性概念的成形，与东方思想关系极深。1929 年，荣格为卫礼贤（Richard Wilhelm）翻译的《太乙金华宗旨》（《金花的秘密》）作解说——道家统观阴阳的相互作用与对立以把握全貌的思路，给了他重要启发。他写道："我们不能将目光仅仅放在意识的世界，要充分了解无意识的重要性，更加关注两者之间的互补作用。这样，就能够悟出我们全人格的中心已经不是自我，而是自性。"荣格的思想因此"像是架在东、西方文化之间的桥梁"。

但要注意，荣格对东方并非全盘接收。他观察到，东方思想很早就关注自性问题，比西方了解得更多，可是"东方人可能会动辄强调自性的伟大，而没有意识到这些或是以牺牲自我为前提的"——为了超越个人的伟大而牺牲个人存在的价值，被内部世界占据整个身心，完全忘掉与外部的联系。书里那个刻薄又精准的例子：在众人面前表演水上行走的瑜伽修行者，沉到水底丢人现眼。他一定在内心世界体验过时间与空间的相对性，但把这种体验无条件地往外部世界扩展时，就出了问题。

荣格的立场是：**自我必须足够强大，强大到有能力主动向无意识的世界敞开大门。**他说："对于自我所具有的片面性，无意识生成了补偿性的象征，意欲成为两者间的桥梁。但没有自我积极的协同姿态，事情是无法发生的。"通过自我与自性间的**对决和协作（Auseinandersetzung）**，才可能走上自性实现的道路。这是荣格在大量吸收东方思维之后，与一般东方思想分道扬镳的地方。

### 3. 两种沉船方式：被吞没，与自我膨胀

体验伟大的自性，伴随着巨大的风险。沉船有两种方式。

第一种：**自性吞没自我**。心灵的整体性全部沉入无意识，无意识特有的"时间、空间的相对性""部分与整体的等同性"直接涌进意识——精神分裂症的妄想性内容就是典型。自我不具备恰当的力量时，就会面临这样的危险。

第二种更隐蔽：**自我与自性同化**，自性的伟大转移给自我，造成"自我膨胀"（ego inflation）。河合隼雄点名了高危职业：时时刻刻与自性正面较量的心理治疗师、宗教家。本来最该谦虚的人显出俗不可耐的傲慢，是一种自我膨胀；还有一种人标榜谦虚的美德，却"没有察觉到面子上的谦虚正是靠着无意识的傲慢贴上一层衬里才得以成立"。

那么，反过来，彻底忘记自性存在的人呢？不断强化意识体系、压抑一切不合理的和劣等的东西，凭强大的自我构筑起地位与财产——走到这一步的人，"有可能会在某一天突然发现自己从这些东西当中再也找不到'意义'"，突然觉察到自己与自己的灵魂完全切断了关系。荣格说过，他的患者中约有三分之一就是因为搞不清人生的意义而来的，其中甚至有人自述"就是因为适应得太好而苦恼"。现代文明为安抚这种焦虑提供了大量暂时忘却的工具——低俗电影、赛车赛马的赌博、为人类节约时间又制造出浪费时间的电视。河合隼雄提醒：我们仅仅嘲笑落水的瑜伽修行者是不够的；但答案也不是把电视洗衣机都扔掉隐于禅寺，而是**在不失去与外界联系的前提下，对自己的内部世界也打开窗户**。

代价呢？在自性实现的路上，人往往要背弃自己深信不疑、绝对正确的东西——一直对思维机能确信不疑的人不得不面对情感机能时束手无策；轻视女性的男性某天发现自己一举一动带着娘娘腔，吃惊不已。荣格的金句："什么都好的东西往往很贵，而人格发展是最高价的东西。"

### 4. "现在这里的所有人，都是我的自性"

一个流传很广的误解是：心理分析就是"通过分析了解自己"，像把内心放在显微镜下窥视。一次荣格讲课结束后，有学生问："先生说的自性实在难以理解，能不能用具体的东西来说明一下自性到底是什么？"荣格回答：**"现在这里的所有人，都是我的自性。"**

这不是禅机，而是理论的必然。荣格说："个性化具有两个主要的方面。首先是内部的和主观的综合过程，同样不可缺失的另一面是客观关系的过程。某一面在某一时刻或许会占据优势的地位，但仅有一面是绝对不能够存在的。"借助投射机制这座桥梁，内部的发展与外部的发展连在一起：在内心探究阴影的人，会把阴影意象投射到朋友、兄弟身上，现实的人际关系随之微妙地纠缠进来；内部阴影的整合取得进步时，外部的人际关系也会改善——内外错综复杂，很难说哪个是哪个的先行条件。所以那些抱着"窥视内心"的期待开始分析的人，早早就要面对改变与他人的关系、甚至与对方对决的人生课题，开始品尝"心理分析"的苦酒。**在割裂了与他人的关系的前提下仅仅了解自己，是不可能存在的。**

### 5. 自性长什么样：老人、孩子、婚礼与曼荼罗

自性实现是终极目标，但**不存在一个静止的终点**——它是持续不断的过程，过程本身就是人生的意义。我们不可能直接认识自性，只能通过它的象征性表现将其功能意识化。

**智慧老人。**当自我在意识层面用尽努力仍打不开局面、陷入绝望时，自性的功能启动——童话里那个突然出现、给出忠告的老者就是它的人格化。荣格举过高加索童话的例子：王子要造一座谁都挑不出缺点的完美寺院，一位老人出现，说"太可惜了，基石不大端正"；王子重建，老人又发现缺陷，就这么重盖了三次。别人眼中完美无缺的东西，他能看出缺陷——这就是自性"在远高于我们现在所处的层面有过解决问题的体验"。东方文化里的仙人正是这类人物的典型：芥川《杜子春》里的仙人，还有扑朔迷离的老子——在"老子"的名义之下，凝聚了东方人怀抱的"智慧老人"意象。女性版本则是大地母亲、至高无上的女神：灰姑娘束手无策时出手相救的仙女。

**圣童。**自性有时反而以孩子的形象出现——"具有老人智慧的孩子"看似矛盾，实则强调自性实现"逐渐形成"（becoming）的特性。圣克里斯托弗的故事是绝好的教材：这个强壮的巨人立志侍奉最强大的人，先随国王，见国王怕恶魔便随恶魔，见恶魔怕十字架便去寻基督。他听从牧师的忠告守在河边浅滩，背人过河。一个暴风雨的夜晚，一个小孩请求他背自己过河——他想小孩子这么轻，很容易。谁知背上的孩子越来越重，脚步越来越沉，到达对岸时他感叹"简直像背负着整个世界一样"，才醒悟背上正是他一直等待的基督。这个故事至少压缩了三层含义：自我所谓的强大相对于自性是那么无力；自性实现的道路总是伴着艰苦的负担；而自性初看上去"不过是个小孩儿而已"——微弱、没价值、容易被忽略。很多人正是这样，觉得一个小孩子的话有什么好听的——直觉型轻视感觉机能、内向者看不起外向者，互相懒得搭理，"在人生的过程中把珍贵的诞生新生命的机会生生地扼杀掉"。顺带一提：神经症患者，就是因为拒绝了自性实现的苦难而不得不体验另一种形式的苦难——这也说明他们内心有自己还未曾察觉的发展可能性。

**婚礼。**当自性的象征强调统合性时，会以相反事物合二为一的男女结合姿态出现——正所谓阴阳的结合。童话以王子与公主结婚收尾，普绪喀历经苦难终与丘比特结合，都是例证；反过来，缺失一半的象征则以"结婚当天新娘或新郎走失了、变成石头了"的形式出现。

**曼荼罗。**当整体性不以人格而以几何图形表现时，就是曼荼罗（mandala）。荣格注意到，患者的梦和幻想中会自发产生以圆、方形为主题的图形，本人未必理解其意义，却经常伴随安宁与和谐的情感，有时甚至是治愈的起点。后来他接触到中国西藏地区的文献，发现东方早已把这类图形作为深刻的宗教对象，称为曼荼罗——患者们不可能都事先了解过东方曼荼罗，对提出集体无意识的荣格来说，这个呼应意义非凡。按栂尾祥云《曼荼罗之研究》的考证，曼荼罗（mandala）由词干曼荼（manda，心髓本质，"用于味道则指将牛奶精炼再精炼以后的醍醐味"）加词尾罗（la，所有、成就）构成——"具有本质心髓"之意，与荣格的自性象征高度一致。荣格的判断是：在一个人经历心灵分离或丧失统合性时，内部意欲整合心灵整体的作用便以曼荼罗的形式表现出来，"这很明显是自然产生的自我治愈（self-healing）的尝试，并不来自意识的自我反省，而是本能的活动"。幼儿园女孩那组画里的第Ⅳ图——家和蜗牛分离后出现的几何形花坛——正是心灵"愈合裂缝，再度走向统合"时的曼荼罗。

曼荼罗通常由**"四"**的主题构成（也有圆、三、五的变体）——"四"是完整之数。第七章末尾那个梦系列里，三位男性加一位陌生女性、由她引导顺流而下的组合，正可解读为四的完整性，以及阿尼玛作为通向自性的中介。此外，兼具几何精密性与贵重难得两种特性的**宝石**也常代表自性——童话里主人公为寻宝石历尽千辛万苦的故事不胜枚举。有趣的是文化对比：西方庭院正正方方、中央圆形喷水池、四角塑像，极重几何；日本庭院几乎处处回避几何对称，更强调石头在自然姿态下的美学与宗教意义——双方都有深刻的宗教含义，不同之处尤其耐人寻味。

### 6. 时机就是一切：印刷厂老板的破产

"自性实现的代价很高"，绝不是地上捡个大钱包的甜蜜故事——有时它甚至具有很强的破坏性，使自性实现的过程沦陷为自我灭亡。荣格举过一个典型例子。

一个印刷工人，经过二十年不懈努力，终于拥有了一家自己经营的大规模印刷企业。生意兴隆，他越来越热衷于工作，所有精力投入其中。正是这份热情筑成了事业的基石——**但也正是这份热情引导他走向毁灭**。几十年里他压抑了生活中其他一切需求，作为补偿，幼年时期对绘画和图案的爱好强烈地浮现出来。如果他能把这份爱好安放在业余领域，本不会出什么问题；但长年受压抑的愿望之强烈，不允许它局限于平淡无奇的余暇兴趣。于是他按照自己幼稚的、未成熟的喜好，把公司的印刷产品都做得更"艺术"。没过几年，事业理所当然地以破产告终。

河合隼雄的分析抓住了一个精确的力学时刻：他倾注给事业的心理能量不断向外扩张、流淌，**当事业到达顶峰"时"，心理能量转向内心世界，开始逆流**。本来静静待在内部世界、具有崇高意义的绘画图案，与外部世界混为一谈，被当成商品输送出去——这正是走向毁灭的关键。如果他能划清内外的界限，认识到内心世界幼稚的一面并逐步摸索与之相处的方法，结局不会这么惨烈。

这个案例引出了本章最后一个大主题：**时间**。荣格反复强调，除了青春期，人生后半还有一个重要的转换期——四十岁左右。人生不是均匀的发展过程，而是在特定时间段呈现出比平时更强烈的趋势，每个飞跃期都必然是"危险的年龄段"。

格林童话里有个欢快的寿命故事：上帝给驴三十年寿命，驴嫌劳役太苦，减去十八年；狗、猴子也嫌长，分别退回十二年和十年。只有人嫌三十年太短，上帝就把驴、狗、猴子退回的年头都加给了人——凑成七十年。于是人过完三十年像人一样的日子后，接着是十八年驴子般辛苦劳作的岁月，然后像一只想咬人但牙都掉光的老狗一样过活，最后是十年猴子般孩子气的生活。这个故事直白地讲出了人生的阶段——以及一个警告：**人最容易犯的错误，是期待前三十年的生活丝毫不变地延续到七十岁**。固执于"年轻""强壮"的卖点热心工作、扩展事业，然后像印刷厂老板那样，给别人看的成功突然止步——活到五十岁、精神上还像三十岁的人，就会身不由己地从年轻时代直接跌落至"猴子的年代"。荣格曾叹息：自古以来的"老年智慧"跑到哪里去了？在美国，父亲变成儿子的好哥哥，母亲恨不得成为女儿的妹妹。而真正想以人的姿态活完整个人生，就要在人生后半段活出"**用走下坡路的方式成就自己的事业**"这样自相矛盾的精彩。日本人对此本不陌生——孔子的"不惑""耳顺"早已成为年龄的别称，东方的宗教哲学里到处是"老人的睿智"；但河合隼雄不忘补一句：不能说日本就没有年轻夫妇正朝着美国父母那样的"理想"努力。

### 7. kairos 与共时性：钟表测不出的时刻

年龄段只是统计规律；对具体的某个人，自性实现的"时刻"何时来临是不确定的，且经常在完全料想不到的时候突然出现——印刷厂老板的少时记忆恰好在事业从上升转向下坡的节点浮上心头；第四章游戏疗法里的孩子第一次主动去洗手、从治疗师手上接过手帕的"时刻"，也完全超出治疗师的预想，不期而至。

借用保罗·蒂里希的术语，河合隼雄区分了两种时间：**kairos**——具有重大意义的时刻，与 **chronos**——钟表测定的单纯时间。自性实现的问题与 kairos 密切相关：一直外向的人到了不得不挖掘内向生活意义的时候，一直专心学习的人突然遇到倾心的异性——忽视这种 kairos，就会在自性实现的路上误入歧途。但一门心思只专注 kairos 而忘记 chronos，也蕴含着生存必需的人格面具遭破坏的危险：上下班、面试、开演、约会，都是社会人必须遵守的规则。书里那个绝妙的例子是相扑：角力的精髓本建立于 kairos 的对峙，原来比赛对力士的对峙完全没有时间限制；到了现代，体育时间表的外界限制越来越多，人们才找出"对峙时间限制"这个在仪式与体育、kairos 与 chronos 之间的妥协方案——横纲至今既是宗教仪式最高祭司，又是最强运动员，两种形象交织，"横纲本人也会演绎出自己的人生悲剧"。

在自性实现的重要时刻，还常会遇到不可思议的现象：一直对绘画没兴趣的人梦到跟朋友去画展，与分析师谈到为了发展感觉机能不妨去看看画展，回到家就接到梦中那位朋友的电话，约他去看画展；第一章里，洗衣机修好的日子孩子的尿床症恰好治愈。荣格非常重视这种"**有意义的偶然一致**"（meaningful coincidence），认为这是不同于因果律的规律，称其为**共时性原理（synchronicity）**——发表时是与物理学家泡利联名出版的，这个事实本身意义非凡。心理治疗迎来转机时共时现象尤其常见，强烈到连当事人都感慨："就这么样偶然加上偶然，再也不能说是单纯的偶然了吧！"但河合隼雄立即划出红线：**再多迈出一步、企图用因果关系来说明共时现象，马上就会陷入伪科学（魔术）的泥淖**——"他因为梦到死去，所以死了""我因为请人祈祷了，所以病好了"，就属此类。共时性的思维方式是：不问"什么是什么的原因"，而专注于"什么和什么同时发生了，它们通过什么样的意义联系在一起"。这种思维中国人特别擅长——《易经》充满了这种类型的知识：不把事象按因果排进时间序列，而是抓住事象整体，从中发现反映全局的"象"。河合隼雄不同意"中国人思维缺乏逻辑性所以没发展出自然科学"的说法：不是逻辑性的问题，而是看待事象万物的根本态度不同。西方充分发展了自然科学，却"把非常'丰富'的'象'的一面深深压抑下去，使得自我失去了与存在于心灵深处的自性的接触"——近年西方不得不花大力气解决"人际关系淡薄"的问题，原因也就在这儿吧。

## 灵魂：还能怎么用

### 隐形假设

这套理论要成立，至少需要几个未言明的前提：(1) **心灵有目的论的方向性**——异常行为、梦、曼荼罗都指向"更高层次的统合"，而不只是随机故障；(2) 存在一个超越意识的整合中心，且它"在远高于我们现在所处的层面有过解决问题的体验"；(3) 内与外通过投射机制真实联动，内部整合能带来外部关系的改善。这三条都无法用实验直接验证——它们是临床解释框架的公理，不是被证明的定理。

### 边界条件

第一，**可证伪性问题在本章达到顶点**。"自性"既包含意识又包含无意识、既是整体又是中心，任何现象都能被解释为它的表现——成功是自我的建设，破产是能量的逆流，异常行为是统合的努力。一个什么都能解释的理论，在波普尔意义上什么也没预测。对此诚实的用法是把它当作**回顾性的意义框架**（帮当事人为已发生之事赋予方向感），而不是预测工具。

第二，**共时性是全书最易滑向神秘主义的概念**。河合隼雄自己已经给出了防滑条款——一旦用因果去"解释"共时现象就落入伪科学；现代认知科学还会补上一刀：确认偏误和巨大的事件基数足以让"有意义的巧合"频繁发生。但迈耶将共时性思路用于摆脱身心医学中"心理问题导致身体伤害"式的单向因果，倒与当代对身心交互的非线性理解有暗合之处。

第三，**盲目乐观的风险是河合隼雄自己写进正文的**。美国式"自我实现"文化只取光明面；而荣格版本的核心恰恰是危险清单：吞没、膨胀、破产、背弃深信之物。任何把"个性化"包装成打卡式成长课程的产品，都删掉了这份清单——也就删掉了理论本身。

第四，脑科学家茂木健一郎在本书解说里指出了根本的困难：**"荣格式对问题的认识方法与细分对象、调查性质的现代科学无法直接连接，这也是无法回避的问题。"**他转述河合隼雄在京都的话：箱庭疗法中部件的标准化、砂子深度、时长规定，对标榜"可再现性""普遍性"的经验科学是必要的，"但走过头了，就与心灵的有机体系、活生生的现场产生了乖离"。这不是替神秘主义开脱，而是承认两种知识形态各有辖区——"路总归是有的"，但这条路至今没有修通。

### 跨域映射

- 发展心理学里，"人生后半的转换期"对应荣格开创、后被通俗化为"中年危机"的研究传统；埃里克森的"生成 vs 停滞""整合 vs 绝望"阶段几乎是个性化过程的学院版。
- 马斯洛的"自我实现"直接受此启发，但正如河合隼雄批评的，美国化的版本剃掉了阴暗面；倒是后来的"创伤后成长"（posttraumatic growth）研究——危机瓦解旧有认知框架后出现更高层次重组——更接近荣格的原意。
- 印刷厂老板的破产，在组织行为学里叫"能力陷阱"：让你成功的那套东西，正是让你毁灭的东西；而"心理能量在顶峰时逆流"的洞察，接近经济学里的边际效用逻辑——同一方向的投入终有收益归零、系统要求再平衡的一刻。
- kairos 与 chronos 的对立，在现象学时间哲学（柏格森的"绵延"对钟表时间）和体育、艺术领域的"心流时刻"研究里都有回声。

### 行动触发

今天做一件事：**给你的"印刷厂老板时刻"做一次预检**。问自己两个问题。第一，我目前全部心理能量流向的那件事（事业、育儿、某个身份），已经到了曲线的哪一段？第二，最近有没有什么"幼稚的""没价值的"念头反复浮上来——少年时的爱好、一个想学的东西、一个小孩子般的请求？如果有，不要做印刷厂老板做的事（把它混进主业、包装成商品），也不要做大多数人做的事（嗤之以鼻，"一个小孩子的话有什么好听的"）——学圣克里斯托弗：把它背起来，放在**划清了内外界限**的位置上，然后留意它变得多重。自性最初出现的样子，往往轻得让你毫不在意。

## 与全书的连接：应反复回归的古典

在无意识分层地图上，本章抵达了最深处、也是最中心的一点。回望来路：类型论（第三章）给出意识的两极，情结（第四章）是个人无意识里的自主分裂体，阴影（第五章）站在个人与集体无意识的交界，意象与梦（第六、七章）是观测仪器，阿尼玛与阿尼姆斯（第八章）是深层的摆渡人——而它们摆渡到的彼岸就是自性：**整合所有这些对立要素的中心**。全书的结构本身就是一条个性化之路的路线图：依次遭遇阴影、阿尼玛（阿尼姆斯），然后是自性。

河合俊雄在本书的阅读推荐里说，父亲写作此书的基础是荣格的《自我与无意识的关系》，并如此评价那本书——乍看是沿着自性实现的过程在推进，"但继续读下去，就会感到书中时常在提示两种可能性，在陷入左右不是、进退维谷的困境时，一章结束，开始进入下一章。所以说，这并不是一本教你如何前进的书，而是促成人们自主地面对自己的人生课题的书"。这句话同样适用于《荣格心理学入门》，也适用于自性本身：它不给答案，它出题。

茂木健一郎在解说里讲过一件小事。初见河合隼雄时，他说起自己梦见一个穿红衣服的五岁小女孩，醒来印象强烈却不知她是谁。河合微微一笑："哦，很有意思啊。"然后问："茂木先生有没有五年前左右开始做的事情？这可能是心中的课题吧。"一句话惊醒了他——那个女孩未必对应现实中的任何人，她可能代表着无意识中被自己忽略的什么东西开始浮现到意识层面了。你看，这正是本章的全部内容在一次日常对话里的显影：自性以一个"不过是个小孩儿"的形象敲门，而一位懂得倾听的人认出了她。

茂木时隔多年重读此书，"如旱天甘霖……就像是水渗进完全干燥的毛巾"，并写下他的结论：**"我坚信，这是一本我们需要反复回归的古典。"**为什么是"反复回归"而不是"读完"？因为自性实现没有静止的终点，过程本身就是人生的意义——一本关于一生功课的书，注定要在人生的不同阶段被重新打开：三十岁读到的是类型与情结，四十岁读到的是能量的逆流，六十岁或许才真正读懂"用走下坡路的方式成就自己的事业"。从荣格到河合隼雄，茂木称之为"灵魂的接力"——生活在现代的我们，有责任继续下去。

下一篇是本系列的收官：《整合与行动：把荣格用进生活》。地图已经画完，该上路了——而这一章已经预先告诉了你路上最重要的两条纪律：带上足够强大的自我，留意那个不期而至的时刻。
