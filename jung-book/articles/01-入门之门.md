# 01 · 入门之门：为什么荣格心理学"不科学"却有效

## 餐巾纸开场

一句话：**当科学只能回答"How"（如何），而你的痛苦在追问"Why"（为什么）时，荣格心理学选择不逃跑——它陪你站在那个无解的问题面前。**

```
  患者的哀号: "他为什么死了?" (Why)
       |
       +--> 医生的回答: "头部外伤" (How)   --> 答非所问, 科学的边界
       |
       +--> 转换: "死究竟是什么?" (What)   --> 哲学/宗教, 治疗师也没答案
       |
       +--> 荣格式路径: 不答, 但不逃
            盯住问题背后的 [情绪波澜]
            陪同走向 [更高层次的平衡]  ==> 这才是心理治疗
```

如果你只能记住一个公式，是这个：

**心理现象学 = 扩展视野 + 主体参与 + 把"心理现实"(psychic reality) 当作事实来对待**

## 骨架：这一部分在说什么

《荣格心理学入门》的开篇——译者的话、前言、第一章——合起来回答一个问题：**荣格心理学到底是一门什么样的学问？它凭什么和"科学的"实验心理学分道扬镳，又凭什么不沦为神秘主义？**

核心答案分三层：

1. **它的出身决定了它的立场。** 荣格心理学来自治疗神经症患者的现实需求，不是实验室的产物。河合隼雄开宗明义："分析心理学(Analytical Psychology)并不以精密、明确的理论体系为骄傲，而是首先致力于探求在实际治疗现场更有效果的方法。"
2. **它的方法论叫"心理现象学"。** 治疗师无法置身事外地观察，必须以主体参与进事象——这使它注定不同于牛顿观察苹果落地式的客观科学。
3. **它不相信处女怀胎，但认真对待"人们相信处女怀胎"这个事实。** 这就是"心理现实"：不讨论其物理真假，而追问其心理意义。

概念地图：

```
  荣格心理学的定位
  ==================
  实验心理学          分析心理学
  (客观科学)          (心灵的学问)
      |                   |
   回答 How           面对 Why
   观察者在外          观察者在场内
   限定领域求精确      扩展视野纳矛盾
      |                   |
      +---- 分野处 -------+
              |
        心理现象学
   "尽最大可能扩展自己的视野,
    以主体参与进事象的方式,
    把握主观和客观认识到的布局"
```

## 血肉：凭什么这么说

### 一个数学系学生的叛逃史

要理解这本书为什么"通过个人体验讲荣格"，得先认识河合隼雄这个人。1952 年从京都大学数学系毕业时，他下决心一辈子做高中教师，为了"保持进步"才进研究生院学心理学——理由朴素得可爱："对于高中老师来说，心理学一定是非常有用的。"

后来的转折充满偶然。他钻研罗夏墨迹测验时，发现权威克洛普弗教授书中有一处怎么也搞不明白，写信提问。没想到教授回信承认自己出错了，"而且到目前为止没有一个人指出来过"。这封信极大地增强了他留学美国的念头。到了 UCLA，克洛普弗给他推荐了福德姆的《荣格心理学入门》，他一读停不下来："就是这个，这就是我一直在寻找的心理学！"

最戏剧性的一幕发生在他接受心理分析时。当听说分析主要是"梦的分析"，这位数学出身、"因为讨厌日本人的非合理性、模棱两可的习性，倾慕西方的合理主义才来美国留学"的年轻人当场翻脸："梦这么不科学的东西，让人无法相信。"

分析师斯皮格尔曼的回答堪称全书第一记重拳：

> "但是，你从来都没体验过梦的分析到底是什么就说它非科学，这样下结论本身才是非科学吧。不管怎么说，先做了试试，然后再判断吧。"

河合"狼狈不堪，但也无以反驳"。随后他做了一个典型的"初始梦"(initial dream)——回顾过去、展望未来，斯皮格尔曼由此说出那句预言："你应该是站在东方和西方中间起到桥梁作用的人。"

注意一个细节：河合的"科学信仰"并没有立刻投降。他"一直没停止攻击荣格心理学的'非科学性'，很多分析的时间往往花在讨论上"。而斯皮格尔曼非但不烦，还送了他一句忠告："你对事物所持的怀疑态度，力量非常强大。希望你一生坚持下去，坚持怀疑一切。"

这就是本书立场的来源：**一个带着怀疑一路走进来的人，才有资格说"这套东西有效"。** 河合在初版前言里坦白：荣格的著作，"读者如果没有实地接受过荣格派精神分析的体验，就更加不知所云"。所以他放弃了全面讲述荣格的"胆大无谋的想法"，改为"通过个人的体验、在自己理解的范围内、用自己的语言来表达"。这不是谦虚的客套——在他看来，荣格心理学中"学问和人是不能分割的"，正如埃伦伯格在《发现无意识》中所说，深层心理学的理论与理论创始者的品格不可分离，弗洛伊德的自我分析和荣格的无意识之旅都是"创造性疾患"(creative illness)。

### Why、How、What：三个疑问词的战争

第一章的论证从一个残酷的场景开始。一位女性即将举行婚礼，最爱的人因交通事故去世。她问："为什么他会死了？"医生回答："因为头部外伤。"——回答完全没有毛病，但这位女性能得到慰藉吗？

河合的诊断精准：这类回答无意中把"为什么"(Why)的问题偷换成了"如何"(How)。医生实际在回答"How did he die?"。他引用物理学家亥姆霍兹的名言："物理学不是为什么的学问，而是如何的学问。"近代自然科学的全部辉煌，恰恰建立在把 Why 转换为 How 的操作上——不去思辨为什么下雨，而去精确记述雨是怎么下的。可是这么辉煌的成就，"面对患者的'他为什么死掉了'的朴素的'为什么'时，却给不出任何有用的回答"。

得不到 Why 的解答，人会再次转换思路，把 Why 置换成 What："死，究竟是什么？"——可这个问题治疗师同样答不上来。能把患者打发去找宗教家和哲学家吗？现实是，"经常还是在不知道解答究竟是什么的情况下不得不继续治疗下去"。

那治疗师究竟能做什么？河合用一个日常场景撬开了答案。孩子问妈妈："树叶为什么会摇晃？""因为在刮风呀。""为什么会刮风呢？"——"为什么"的链条理论上无限延伸，但现实中总能在适当的时机被切断。为什么能切断？因为**疑问从来不只是知识问题，背后有情绪的波动**：孩子发问时带着惊奇和内心的高扬，在母亲一步步的回答中，情绪归于平静，心理得到满足。反过来，不会切断链条的孩子会怎样？继续追问"为什么会刮风"，妈妈火上来了："烦死了！"——新提问打破了刚刚获得的平衡，发火是在拒绝威胁平衡的局面。

由此得出全章的枢纽命题：**"Why"的疑问同时包含知识面和情绪面。** 自夏娃吃了禁果——也就是人类有了意识(consciousness)——以来，"为什么"就是人类构筑意识体系的力矩：情绪高扬、归于平静、新内容被整合进意识体系，循环往复。

于是心理治疗师的作用清晰了：面对"死究竟是什么"这种给不出答案的问题，把注意力从问题本身移开，专注于背后的情感波澜——"面对因爱人的突然死亡而感情激烈起伏的患者，我们应致力于陪同患者共同走过恢复平衡状态的过程"。当患者迫于选择 A 或者 B 时，治疗师即使给不出任何知识性解答，也要"坚持与患者共同体验其苦恼"，让患者自己找到超越 A 和 B 的解决方法。河合的定义掷地有声：所谓心理治疗师，就是"面对患者发出的'Why'的哀号时，不随意地把它置换成'How'，而是勇敢站在赤裸裸的'Why'面前"的一类人。

### 洗衣机与尿床：因果律失灵的现场

但"扩展视野"是有代价的。第一个代价：**观察者被卷入现象。** 治疗师敞开心扉倾听时，自己的内心也开始激昂、不安、恐慌——他一边体验一边观察，患者又观察着他的态度，被诱发出新的内心活动。"主体和客体微妙地交叉混合在一起，构建起一个无止境的动态场。"河合的比喻惊心动魄：这时的治疗师不是观察苹果落地的牛顿，而"更像是手提白刃站在敌人面前的剑士，对方和自己的任何动静都有着微妙的牵连，瞬息万变中甚至潜藏着失去生命的危险"。

第二个代价：**遭遇因果律无法消化的事实。** 河合给出了自己的真实案例。他用游戏疗法治疗一个尿床的小学生，孩子在游戏中对坏了的玩具和洗衣机发生兴趣，开始修理。几次治疗后，洗衣机能顺畅排水了——很巧合，孩子的尿床症也完全治愈。

怎么解释？说"因为修好了洗衣机的排水功能，所以不尿床了"，进而发明一套"洗衣机式尿床症治疗法"？荒诞无稽。那就归为"偶然"，弃之不顾？最轻松，但"完全与'视野扩展'的原则背道而驰。说它偶然也罢，付诸一笑也罢，事实就在那里存在着，不可动摇。"

同样的困境出现在"预知梦"上：梦到伯父之死，醒来就收到伯父去世的电报。人们通常两种反应——要么嗤之以鼻当作巧合，要么用"精神电流"之类的念头构筑伪科学。河合两边都批评：伪科学的谬误稍有逻辑就能判断（世上有很多梦见伯父死去可伯父活得好好的例子）；但"因此完全否定'预知梦'现象的意义，也是不可取的"。

这里他引了罗素对物理学的犀利观察："物理学并不是因为我们熟知物理世界而呈现数学性质，反倒是因为我们对物理世界毫无所知才具有数学性质。我们能够发现的仅限于其数学性质而已。"客观科学能成立，前提是**限定一个适当的领域**——把观察者的主体、因果律解释不了的事象统统排除在外。而心理治疗师干的事恰恰相反：既要面对现象，又不能限定领域。日常的困难就在这个纠葛之中。

### 心理现实：荣格不信处女怀胎，但认真对待它

那么，科学解释不了的地方，就可以说"人有精神和灵验"吗？河合警惕这条捷径。他先借荣格敲打了"时代精神"：时代精神"是与理性没有任何关系的信条，却成为所有真理的绝对基准，总是被认为与良知为伍而碾压一切"。荣格的要求是：不做搭时代精神顺风车的人，而"做一个尽可能尊重事实的科学家"。

对精神与物质如何取舍，荣格的回答是不取舍：

> "自然和精神(nature and spirit)的纠葛，正是心灵存在中悖论的反映。正因为我们对心灵的存在一无所知，它才对我们呈现出相互矛盾的精神面和物质面。……只要我们还是诚实的，就不能厌弃由此带来的矛盾。"

落到操作层面，就是"心理现实"(psychic reality)这个概念。荣格举的例子是玛利亚的处女怀胎：合理主义的欧洲人竟然世世代代相信处女怀胎！心理学家既不去讨论它的非科学性，也不试图科学地证明它——"作为存在事实，我们不认可处女怀胎，但努力思考存在处女怀胎思想的意义"。众多人共同信仰这件事本身，就是需要追究其意义的心理现象。河合特意强调：荣格因此遭到很多表面的误解，好像他相信处女怀胎、炼金术是事实一样——"荣格绝对没有把这些当作事实去相信"，"就算荣格不是一个合理主义者，但他也绝对不是一个非合理主义者"。

### 现象学的光谱：从雅斯贝尔斯到罗杰斯

"现象学"(phenomenology)这个词，每个学者都有自己的用法。河合排了一个谱系，坐标轴是"主体参与的程度"：

```
  主体参与少 <--------------------------------> 主体参与深
  雅斯贝尔斯        罗杰斯          博斯         荣格/河合
  纯粹记述,       尊重内省,      本质直观,     主体参与 +
  排除观察者      重治疗师态度    排除一切前提   带着框架逼近
      |              |              |             |
  记述明晰但      忽视治疗师      记述本身       "向现象学
  "阻塞了与患者    人格; 止步于    变得极端       逼近"
  接近的道路"     现象场          困难
```

雅斯贝尔斯主张尽可能排除观察者、贯彻纯粹记述，记述因此非常明晰——但代价是"他的方法阻塞了与患者接近的道路，使得心理治疗变得几无可能"。博斯走向另一极，强调排除一切价值判断、甚至排除主客区别的本质直观——但彻底做到这一步，"记述本身就伴随着极端困难"。罗杰斯在美国土壤上强调治疗师的态度而非解释技术，功绩卓著，但"基本上止步于对内省的尊重"，没有像欧洲现象学者那样扩展到心灵领域。

河合的立场最有实践者的体温。面对"对来访者，不拘泥于任何条条框框，见了再说"的流行倾向，他坦白："笔者虽极力在解释现象学逼近法，但还是不敢'不拘泥于任何条条框框'。"他坚持带着"一定程度体系化的知识"（对他而言就是荣格心理学）去见患者——但这个框架不是概念性的教条，而是"通过努力得到的主体经验的成果"，并且必须保持"比照现象进而改进框架的柔软姿态"。否则，"赤膊上阵"式的努力会被无意识的自卫本能搅扰而空转，"心理咨询现场也就演变成为一块不毛之地"。他给自己的方法起了个谦逊的名字：与其说是"现象学的逼近法"，不如说是"向现象学逼近"。

他的最终定义值得原文抄录：所谓现象学，就是**"在尽最大可能努力扩展自己的视野的同时，以自己的主体参与进事象的方式，尽可能准确地把握通过主观和客观认识到的一种布局"**。而当被问到心理治疗师的使命时，斯皮格尔曼的回答只有一个短语："soul 的研究"(study of the soul)。河合说，这句话准确地诠释了"心理现象学"。

## 灵魂：还能怎么用

**隐形假设。** 这套论证有几个没有明说但必须成立的前提：(1) 情绪的"平衡—失衡—更高层次平衡"的动态是真实存在且可被陪伴促成的——如果情绪波澜不能通过关系性的在场得到转化，"陪同"就只是安慰剂；(2) 治疗师的主体参与利大于弊——剑士的比喻同时意味着，一个人格不成熟的治疗师会把自己的问题带进那个"动态场"（河合承认这需要治疗师"充分地敞开心扉"，且"并不是什么情况下都能达到期待的效果"）；(3) "有效"本身可以在不满足客观科学标准的情况下被确认。第三条是最脆弱的一环。

**边界条件。** 诚实地说，从现代心理学看，这一章有几处需要警惕。其一，"洗衣机与尿床"案例正是**可证伪性**(falsifiability)问题的标本：治愈了归功于治疗过程，没治愈也总能找到解释——波普尔对精神分析的经典批评在这里同样适用。河合的辩护（"事实就在那里存在着"）是现象学的诚实，但不构成因果证据；今天我们知道，单案例的巧合恰恰是最需要用对照设计去检验的东西。其二，循证治疗运动已经表明，心理治疗的效果**可以**被随机对照试验研究——"心灵的学问不可客观化"这个前提在半个多世纪后被部分推翻了；有趣的是，研究反复证实的最强效果因子恰恰是"治疗关系"本身，这又意外地为河合"陪同的姿态"提供了实证背书。其三，对"预知梦"的开放态度，今天更可能用记忆的选择性偏差和基数谬误来解释——不过河合对"精神电流式伪科学"的批判，放在今天依然锋利。荣格心理学的正确用法不是拿它当因果科学，而是当作**意义的语法**。

**跨域映射。** Why→How 的转换，在科学哲学里就是"解释 (explanation) 与理解 (understanding) 之分"——狄尔泰所说的自然科学"说明"、精神科学"理解"。"观察者被卷入现象"在物理学里让人想到测量问题，在人类学里叫参与式观察 (participant observation)，在管理学里是霍桑效应。"带着框架又随时修正框架"就是贝叶斯更新，也是解释学循环 (hermeneutic circle)。而"不回答问题、陪同对方穿越情绪抵达更高平衡"——今天的产品经理会认出这是"用户要的不是钻头，是墙上的洞"的深层版本：用户要的甚至不是洞，是挂上照片时的安心。

**行动触发。** 今天就能做的一件事：下次有人向你倾诉不幸并问"为什么会这样"时，忍住给出 How 式解释（"因为你当时应该……"）的冲动。识别一下：对方要的是信息，还是陪同？如果是后者，试着只回应情绪本身。你会亲身验证这一章的核心命题——正确的答案未必是有用的回答。

## 与全书的连接

在荣格体系的地图上，这一章还没有进入任何具体地形——它是画地图之前对"绘图法"的声明。后面所有的概念——情结、原型、阿尼玛、自性——都必须放在"心理现实"的框架下理解：它们不是脑成像里能定位的实体，而是在治疗现场反复被观察到、具有把握人心之效力的**布局**。忘记这一点，就会犯"以为荣格相信处女怀胎"式的错误；记住这一点，才能既不迷信也不错过。

```
  [第一章] 方法论声明: 心理现象学
      |
```

河合在前言里已经埋下伏笔：弗洛伊德的决定论色彩"使得持批判态度的阿德勒和荣格相继远离"。而荣格面对分岔的方式很特别——他"并没有草率地对作为先行者的弗洛伊德和阿德勒两人做出孰优孰劣的评价"，而是追问：为什么面对同样的现象，会产生如此不同的理论？答案指向了人的类型的差异。下一篇《三巨头分岔口》，我们就去看这场深层心理学史上最著名的分手，以及荣格从中提炼出的东西。
