# 06 · 意象与象征：无意识的母语

> 系列第 6 篇 · 素材：《荣格心理学入门》第六章"意象与象征"

## 餐巾纸开场

一句话：**无意识不会说概念的语言，它用意象（image）说话；当一个意象把无法调和的对立面统合成再也找不到更好表达的东西时，它就升格为象征（symbol）——那是心灵正在创造新事物的现场。**

```
   意识世界                      无意识世界
   +--------------+             +--------------+
   |  概念/理念    |             |  原型         |
   |  明确 clarity | <--意象--> |  生命力       |
   |  秩序井然     |   (母胎)    |  vitality    |
   +--------------+             +--------------+
          |                            |
          +---- 对立僵持 -> 能量退行 ---+
                       |
                       v
              象征 = 超越对立的新表达
              (心理能量重新前行,注入自我)
```

荣格的判词：**"理念的特征在于其明确性（clarity），原始意象的特征在于其生命力（vitality）。"** 河合隼雄称之为名言——整章都是这句话的展开。

## 骨架：这章在说什么

**核心问题**：上一章说了，原型本身不可直接认识，只能通过它对意识的作用效果去探知。那么，这个"作用效果"以什么形式呈现？我们凭什么读它、又该怎么读？

**核心答案**：以意象的形式。意象存在于意识与无意识的相互关系中，是**每一瞬间无意识以及意识领域心理状况的集约表现**——像一张即时快照，把当下整个心灵的布局压缩在一个具体的像里。而当意象承担起统合对立物的任务、成为某种未知事物的最优表达时，它就是象征。荣格严格区分象征与符号（sign），并把着眼于意象和象征的研究视为自己心理学的显著特征。

**概念地图**：

```
  意象的三个性质                     象征
  +------------+          +--------------------+
  | 具象性      |          | 象征 vs 符号        |
  | 集约性      | --升级-> | 象征的创造性        |
  | 直接性      |          | 超越功能            |
  +------------+          +--------------------+
        |                          |
        +--------- 落地 -----------+
                   |
          心理治疗中的意象
     (游戏疗法 / 心理咨询 / 箱庭疗法)
```

## 血肉之一：意象——理念的母胎，排中律失效的世界

先划清边界。荣格说的意象，基本上不是"对外部客体的再现"那种一般含义（河合隼雄在注释里特意提醒：这与多数学者把 image 理解为"没有外界刺激时感觉的再现、二次感觉"很不一样）。它是**心灵内部的活动**，与外部现实只有间接联系，是无意识层面的产物。它也不是幻觉——幻觉是把内部意象误当作外部事实而产生混乱的病态；意象没有这种混乱，它看上去不被"外部和现实"认可，却对具体的个人有着极其重要的内部价值。

河合隼雄从三个方面拆解意象。

**其一，具象性。** 内部意象处于形成明确理念之前的阶段——意象是生发理念的母胎。我们有意识地思考时，用的是概念；而每个概念背后都以某种意象为母胎，通过它间接连着无意识。麻烦在于，概念层面的规则和无意识层面的秩序犬牙交错，并不统一。在意识世界里属性明确、秩序井然的分类，进到意象世界就被完全打乱，重新集约为"父亲像""母亲像"这样的东西。意象世界破坏了时间、空间秩序，甚至连排中律都可以被忽略——"部分相等，那么全体就相等"这样不合理的规则在这里行得通。于是不相等的事物时常被认为等同：**母亲、漩涡、壶，作为相同的事物存在**（还记得上一章"肉的漩涡"之梦吗）。

具象性是双刃剑。第三章那个扑克牌的梦里，当事人手上的牌一张红桃（心）都没有——这个极其具体的形象，生动传达了他的现状，成了他思考人生的素材。但形象太具体，注意力容易被吸走，反而忽略事态的真实意义。河合隼雄有个妙喻：**意象站在数学的另一个极端**。数学太抽象，让人畏惧；意象太具体，让人不是觉得难懂，而是觉得不可置信。可正是这种"没个正经样子"的意象，一旦在形成过程中聚集了足够的心理能量，就能成为破坏意识世界概念组织的强大力量——内心一直立着威严恐怖的父亲像的人，遇到地位比自己高的人就自动重叠上这个像，人际关系怎么也和谐不起来。对社交恐惧症的人极力说明"人没什么可怕的"，毫无作用；合理的解释在意象面前苍白无力。心理治疗师的特殊任务，正是在充满非合理性的意象世界里寻求答案——通过自己主体的参与，与患者共同体验那个世界。

**其二，集约性。** 用荣格的话说，意象"是心灵整体的集约表现"。不是说它代表了无意识的全部内容，而是在适当时机形成的一种布局（momentarily constellated）——一面是无意识的产物，一面依存于当时的意识状态。上一章脸红恐惧症的梦是绝好的例子：梦里给人难堪的数学老师，像当军人的伯父；父亲也是军人气质，母亲却爱文学音乐；自己性格像母亲，从小怕父亲，服兵役时遭受凄惨待遇；数学是短板，解不出题很丢人；同学讥讽自己奇怪的名字——本人讨厌这名字，父亲却觉得挺值得骄傲……**一位数学老师的形象，同时凝聚了恐惧、厌恶、自卑，连着父亲、伯父、军人、同学与数学**。众多事象在内心形成一个布局，梦把它活灵活现地表现出来。一个意象，顶得上一份人生档案。

**其三，直接性。** 假设我们跳过梦的分析，直接给扑克牌之梦的当事人提建议："你的思维机能很出色，但太不在意情感机能了，以后要注意多发展。"——会怎样？河合隼雄的回答很干脆：玩弄"情感""思维"等文字游戏，远不如梦中"一副牌里一张红桃（心）都没有"来得印象深刻。从知识入手讲道理，很难触及心灵深处；**直接的体验才是促人心动的根本力量**。意象表达形式之丰富、触及心灵的力量之强大，令人惊叹。

但直接性也带来两个陷阱，河合隼雄用两个比喻说透了：

```
  只要概念,忘掉意象        只泡在意象里,不提炼概念
  = 没有水浇灌的植物       = 用湿木材盖房子
    总有一天枯死             到处变形,房子不成房子
```

我们需要从意象中剥离具象性、提炼升华到理念层面；又不能让概念断了与意象母胎的联系。荣格那句"理念的明确性 vs 原始意象的生命力"，说的正是这两端的张力——而且他指的是原始意象，这种倾向比个人意象更强烈。

还有一层诚实的坦白值得记录：意象的个人性使它**极难向外人传达**。治疗师和患者有时会心灵相通、一起大笑不止，可想把这感觉讲给第三人听，对方一脸迷茫："这人在说什么傻话呢？"河合隼雄自己都不安：扑克牌的梦、数学老师的梦，"没准儿读者中也会有人觉得傻乎乎的"。而对体验过意象冲击力的人来说，一切"解释"的努力反倒像剥夺意象生命力的小聪明——他自己讲的情感机能、父亲像，"都可以说是画蛇添足吧"。明知不完全，仍然要用概念去讲——这种两头不讨好的姿态，恰恰是对待意象唯一诚实的姿态。

## 血肉之二：象征不是符号——十字架与马歇·马叟

意象是产生新事物的母胎，最能体现其创造性一面的，是象征。荣格对象征与符号的区分极其严格：

- **符号（sign）**：用来代替已知事物的表现方式，或已知事物的简称。
- **象征（symbol）**：不是已知事物的代用品，而是**意欲表述某种未知事物时产生的最优方式**——再也找不到更合适的表现形式。

荣格自己举的例子：把十字架当作"上帝之爱"的象征？不对——如果十字架的意义能用"上帝的爱"这个词完整表达，那就没必要用十字架，这只是符号性的说明。但如果十字架指向的是至今未曾得到任何认知的超越性事物，除此之外再找不到更合适的表达，那它才是象征。顺着这个标准，河合隼雄捅了弗洛伊德一刀：弗洛伊德所谓梦中的性象征，如果仅仅因为形状比较长就看作男性性器的表现，那与其叫"象征"，不如叫"符号"更贴切。

区分的最好教具是哑剧。手势哑谜游戏里，谁都能表演"人的一生"：手脚并用在地上爬、走、拄拐杖、躺地上死去——给谁看都明白。但这只是人一生的**符号**。哑剧名人马歇·马叟在两三分钟里演绎人从出生到成长到死亡的过程，充满一生的悲欢、内心流淌的形形色色的思绪和情感，直诉胸臆，给全场观众带来深深的感动——只有马叟能表达到这个层次，早已无法用符号替代，是他**通过自己的人格**才能做到的象征性表现。

这里有个关键推论：**一个事物有没有象征意义，很大程度上取决于接受方的态度。** 初期基督教时代，十字架是活生生的象征，其难以表达的神秘含义被信徒内在化；随着时代流逝，它慢慢只是标示信徒身份的符号；对毫无关系的人，可能不过是两根组合起来的毫无意义的直线。同一个东西，可以是象征、符号或什么都不是——像艺术品，对某人有不可替代的意义，另一个人看不出任何意思。所以，试图汲取象征意义的人，必须**对每一件事物背后未知的可能性持开放态度**。这是必要条件。

## 血肉之三：五幅蜗牛画——一个六岁女孩的分离与整合

理论说完，看实例。河合隼雄拿出五幅幼儿园女孩的画——不是治疗中的作品，是六岁女孩在不限制孩子行动的幼儿园里，想画什么就自由画什么的日常之作。这一点很重要：无意识的表达不需要诊室，它随时在进行。

他偶然看到第 II 幅时"内心深受感动"：**左边的家和右边的一群蜗牛之间，耸立着严格区分两者的高山**。六岁左右，孩子在第一次反抗期之后再次倾向更高层次的自立——之前在家庭内找到安居之所的孩子，开始向往进入社会。画里，蜗牛和家分离了，简直像专为分开两者而拔地而起一座高山；山上两棵树，透着强烈的成长力和向外延伸的生命力（注释里补了一笔：树常被当作成长的象征，如"生命之树"Lebensbaum；"二"既表达"纠葛"，也说明"距离意识比较近"）。

他推测：之前应该有过表现家庭内部温暖感觉的画。请老师找出稍早的第 I 幅——果然，画面整体温暖，中央红色的蜗牛安心住在家里；但左边很多蜗牛用冷色调画成，或许已预示后来的分离。同期另一幅画基调很暖，却有一部分被绿色框住、有些地方留着空白——同样一定程度暗示着将来的分离。

第 II 幅冲破安稳、出现力量之后，"毫无疑问还需要再次整合的努力"。III、IV、V 三幅的共同点是左右分割的主题——继承了分离的力量，又能感受到认可分离前提下的整合努力：

- **图 III**：中央一条大道，右边是家，左边有人，本有鸟瞰图的味道；画着画着中间冒出一棵大树，视点混乱，画不下去了，右侧被涂掉不少。**尽力在整合，却难以简单成就其过程**——失败本身就是记录。
- **图 IV**：用花田的鸟瞰图找到了绝妙的形式，画面分成四部分。代价是画变得接近几何图形，失去了趣味性——既要容许纵向分割又要构造整体性，对幼儿太难，她牺牲了绘画表现力，用形式化手段完成了高难度任务。表达整合性时经常产生"四"的主题——荣格不止一次讲"四"具有"完整数"的意义，他著作中一位成人患者的画里同样有清晰的"四"的表达。
- **图 V**：好像为了让缺乏感情动线的图 IV 透一口气，生动活泼起来。左边女孩儿，右边家，中央大树，家用红色包围，女孩儿在绿色丛中——依然是分离，但**树上画了一个孩子**。

树上的孩子让河合隼雄非常欣喜。世界各地流传的从树里出生的孩子、被遗弃到树下的婴儿的传说，最直白地讲述着从"生长的象征"中诞生新生命的主题。借用荣格的表达，这恰恰象征着英雄的诞生、**儿童原型（child archetype）的出现**——为促使处于分离状态的家和人再次整合而出现的英雄。荣格和柯列尼在合著中明确过这一事实；柯列尼极力强调神话里儿童神在代表"新的可能性的出现"上具有比成人神更深刻的意义。而"未知的新的可能性"超越一般理解，所以新生儿诞生的话题往往以荒诞的形式出现——桃子里生出的英雄、竹子里诞生的绝世美女，在日本家喻户晓。

然后是全书最可爱的一次自嘲。幼儿园老师解释说：这画的是《杰克和豌豆》，听了故事之后孩子画的；左边的"女孩儿"是杰克的妈妈，树上的孩子是爬豌豆树的杰克。"什么呀，说了半天原来不过是这么回事"——河合隼雄主动引了《徒然草》里的吉田上人：看到被孩子调皮放反的石狮子，以为有深奥的由来，呜咽不止。"读者看我在这里滔滔不绝地讲原型性儿童的诞生，肯定把我也当作吉田上人的同类吧。"

但他随即给出了更深一层的看法，这一层才是本章的筋骨：**杰克和豌豆的故事恰巧在适当的时候出现，给这位女孩儿的内心状态提供了富有生命力的表达方式。** 证据有三。其一，孩子是在完全自由的活动时间里、不受任何约束地画了这幅画——故事中的意象准确捕捉到了她当时的内心活动。其二，看同期其他孩子的画，几乎都画朝天伸展的豌豆树和爬树的杰克，**几乎没人画"杰克与巨人作战"**——冲天生长、不停向上攀登的意象，对这个年龄段的孩子有特别的吸引力。其三，女孩儿之后的画仍延续中央一棵大树的主题、"四"的数字，但不再把画面生生切成两半，生硬的对称消失，整体性呈现出来——发展在继续。时常给孩子讲童话、寓言，意义正在这里：故事为说不出的内心状态提供现成而鲜活的表达容器。

还有一个旁证令人深思。画第 II 幅前后那段时间，这个在大人眼里文文静静的乖孩子，反倒总被班里调皮的男孩子欺负——老师去阻止，男孩子们却说**她最近很嚣张，要教训教训她**。同龄的孩子或许在某一点上觉察到了她内心如此强烈的自立意向，因而产生抵制。大人看到的是"乖"，孩子们感知到的是正在破土的力量——无意识的变化，先于一切外显行为被同类嗅到。

## 血肉之四：象征怎样形成——退行、物极必反与超越功能

象征总是具有**对立事物的统合性**——五幅画就是把家与孩子当作对立事物、向着再次整合努力的过程。对立物越多、关系越微妙，统合上升到更高一层，象征的构造愈复杂，创造性也愈高涨。河合隼雄举了两个艺术例子：浮世绘画家直观把握对象本质却绝不超出对事物外部的表现（甚至可以说是写实的），是感觉机能与直觉能力的绝妙统合；卡拉扬的指挥，紧闭的双眼对着内心世界开放、有深厚的内倾志向，华丽的动作却像特意做给听众看一样不断向外扩展——外向性和内向性两个完全相反的特性完美统合在一个人身上，形成象征性的表现。反过来说，只依赖思考且完全无视情感的哲学家、感觉发达却缺乏直觉的音乐家，我们可以承认其正确性，却无法感受到创造力。

那么象征形成的机制是什么？荣格的描述可以整理成一条链：

```
 意识到两个相反的倾向,无法选边站
        |
        v
 自我停滞(跟命题和反命题都有不解之缘,压抑哪边都不行)
        |
        v
 心理能量从自我领域退行到无意识(回归源泉,诱发无意识活动)
        |
   +----+---------------------------+
   |                                |
   v                                v
 自我撑不住 -> enantiodromia      自我弱化机能后仍忍耐着持续运行
 "物极必反,相反相成"                     |
 态度180度逆转,仅是逆转                  v
 无任何创造性变化              出现超越命题与反命题的统合性意象
                                    = 象征
                                       |
                                       v
                          退行的能量再次前行,注入自我
                          自我获得新能量开始活动
```

具体化一下：一位以思维为优势机能的思想家，某天突然觉得自己的思考乏味、缺了关键的东西——被忽视的情感机能开始活动了。压抑住它继续照常思考，不会出大问题，但思考欠缺创造性；忠实于情感又不抛弃思维，两者的对立会把他拖入困境：像是放弃了有意义的思考、耽于无谓的空想，时不时冒出幼儿式的冲动，静不下心，搞不清自己想干什么，每日焦虑烦躁。若退行强烈到自我难以忍受，就出现"物极必反"（enantiodromia）：思维型的人突然变得非常感情用事，内向的人突然做出强烈外向的行为——从一个极端到另一个极端，激烈却没有创造性意义。**而如果自我能忍耐着继续运行，无意识的倾向和自我的作用就会超越单纯的命题与反命题，出现具有统合意义的意象——这就是象征。**

荣格把人形成象征的这种能力称为**超越功能（transcendent function）**。纠结它属于思维还是直觉已没有意义——它合成多种机能，甚至包含完全对立的机能在内。象征形成的过程等同于创造过程；荣格所说的无意识的肯定性和创造性的源泉，就在这里。

于是必须重估退行。弗洛伊德认为无意识是被自我压抑、排斥的内容之集合，退行永恒地代表病态；荣格则先区分退行是病态还是正常范围，并认为**创造性的人生必然需要正常范围内的退行**——当然是在承认无意识的破坏性和丑恶一面的基础上，寻求其成为建设性源泉的可能。这种基本态度成为他与弗洛伊德诀别的一个重要原因。而历史开了个和解的玩笑：河合隼雄在注释里指出，近期自我心理学者中有人强调的**"为了自我的退行"（regression in the service of the ego）**，与荣格所述创造性所需的退行现象表现出同样的过程——仅从这一点看，现在的荣格派和弗洛伊德派比以前更加接近了。当年分道扬镳的理由，几十年后成了两派重新靠近的桥。

意识体系由明确的概念构成，本身具有整体性；但要充满活力地持续发展，它必须与心灵深处建立联系。**意象是来自心灵深层部分向着自我诉说的语言**——神经症患者中，不少人正是断绝了自我与无意识之间的创造性互动，或不能理解意象的意义，以致概念世界混乱、自我统合性受到威胁。所以研究意象与象征，对治疗师不是学术趣味，是日常工作。也因此，荣格晚年致力于研究远古产生、后来失传的宗教仪式及象征的意义——他发现心理能量的变容正来自象征及宗教仪式，在给古老事物赋予新意的同时，更看到了每个人内心产生的象征的意义。

## 血肉之五：治疗现场的意象——解开绳子的孩子与生孩子的表妹

**例一：游戏治疗中的"解除束缚"。** 这是京都大学教育学部研究生院东山纮久的治疗实例。七岁十一个月的男童，发育年龄只有一岁九个月，无法与同龄孩子玩耍，一直闷在家里过着孤独的生活。游戏治疗到第七次，孩子反复做一件事：**用绳子缠在玩具熊的脖子上，拖着走一阵子，再把绳子解开。** 治疗师当时并不明确理解其意义，但内心受到震动。

事后与跟母亲对话的咨询师核对才知道背景：家里来了一条迷路的小狗，孩子高兴地喂养它；有天狗不见了，妈妈说要出去找，孩子却说不用找了。原来是邻居的狗，主人找上门来——**独自在家的孩子听懂了狗主人的话，自己把心爱的小狗牵来，一边哭一边把链子解开，还给了主人。** 一个基本不会说话的孩子完成了这样的事，妈妈又惊又喜。

游戏是在向治疗师讲述这件"大事"的经过吗？是，但不止。河合隼雄在一再重复的行为中看到一个生动的主题：**解除束缚**。追问之下果然有呼应——因为智能障碍，母亲一直把孩子放在家里不带出门，孩子像活在某种囚禁状态下；后来为了治疗不得不出门，妈妈的想法转变，渐渐不再限制他外出。给玩具熊解开绳索的游戏（几乎可以称为仪式），凝聚了从家里挣脱束缚被解放的强烈印象、还回小狗的悲伤、能与邻居对等交流并控制住悲伤的成就感——**各种复杂情感凝聚在一个游戏里**，所以它有着与之前的游戏不同的感染力，治疗师才会心动。发育年龄一岁九个月的孩子，表达出这样的内容——河合隼雄说，**意象形式的表达深度，常常无关乎智能、年龄**。

治疗师对意象世界敞开心怀，游戏内容会渐渐变得意义深刻，从中能读出贯穿始终的主题：离家出走、在家庭内部寻求安住的位置、一直压抑着的攻击性的整合（参考第四章洁癖的例子）……理解到这一层，对把握治疗走向、增加治疗过程的稳定性都很重要。注释里补充了两个重要事实：其一，因为孩子容易把心像以更整体的形式表现出来，河合隼雄近来在游戏疗法中并用**"箱庭疗法"（Sand Play Technique，也称沙盘疗法）**；其二，京都市心理咨询中心大谷的实例报告里，孩子玩超人和怪兽斗争的游戏——**途中超人失败死去被埋进地下，然后又活过来打败了怪兽**。在游戏中戏剧性地完成了"死和重生"的过程，随后孩子的症状渐渐好转。死与重生——退行到底、然后携新的力量归来——正是上一节象征形成机制的儿童剧场版。

**例二：心理咨询中的表妹。** 这是京都市心理咨询中心中村良之助的实例。一位年轻女性在咨询中不说自己的烦恼，一直讲表妹：表妹在以为无法生育、快要绝望时有了孩子，高兴得不得了；表妹花钱一点不在乎，而自己一直认为节约俭朴是美德，但看到表妹买下喜欢的东西后高兴的样子，"想想有时候浪费一下也挺好的"……

只在表层听，会觉得她在回避自己的问题、拿别人的事塞满时间。但把这些当作意象的表现来听，就能察觉：**表妹可能正是这位女性的阴影**（参见上一章）。她一直视"浪费"为绝对的恶习，却通过表妹这个具体的形象，讲述着对自己阴影的洞察——这种伴随深层体验的洞察，远比头脑里想一句"过于节约也不太好"有力量。理性理解一件事出乎意料地简单，但那种理解往往不具备促进行为改变的力量；对神经症患者苦口婆心讲道理基本没效果，**通过活生生的意象体验到的东西却能触动内心**。更有趣的是：回忆一下孩子诞生的原型性意义——新的可能性的出现——再听她的叙述，就能感受到她在讲："以浪费恶习为代表的自己的阴影中，从未意料到也可以诞生新的可能性，而新的可能性诞生了。"外部事象与意象世界之间不可思议的呼应，治疗现场经常可以体验到。

但河合隼雄立刻竖起一块警示牌，这一段在方法论上极其珍贵。说"表妹生孩子的事实表现出当事人整合阴影的新的发展可能性"，或者说"因为表妹生了孩子，所以当事人具有了新的可能性"——**都是荒诞无稽的**。这里没有因果推理，只是"这种观察方法可以成立"、叙述内容与内心世界有呼应关系，仅此而已。所以治疗师要非常慎重地选择词语：不能把内心浮现的内容不做提炼、以原始状态全盘托出，而要找到**既可以成为内心世界的表现、也能够成为外部事象描写的、居于两者之间的表达方式**——比如"在认为已经不可能有新的事物出现时，出现了新的事物"。当事人有呼应，就顺着呼应渐渐深化；毫无共鸣，就暂时放下不谈。无视对方反应、自说自话，终究只是把理论解释强加到别人头上，不具有任何治疗意义。

两个例子的共同点：当事人把实际发生的事情通过游戏再现或语言叙述，经由与治疗师的内心交流，**用意象世界里有意义的体验在自己的心灵深处构筑更坚实的基础**。柯列尼说神话的作用不是单纯的说明，而是为了构筑事物的基础（参见第五章）——这个观点正好适用于此。而真正的意象与象征的宝库，是意识与无意识交错的梦的世界。荣格为什么倾注大量心血研究梦，到这里已经不言自明——那是下一章的内容。

## 灵魂：还能怎么用

**隐形假设。** 这一章成立的前提至少有三个。第一，无意识不仅在"储存"，还在"表达"——它有向自我诉说的意向性，意象是它的语言。第二，这种语言虽然个人色彩强烈，却是原则上可读的（治疗师可以通过训练学会读）。第三，也是最强的一个：外部事象与内心世界存在"呼应"——表妹生孩子恰好呼应着当事人阴影中的新可能，杰克的故事恰好在适当的时候来到女孩儿面前。河合隼雄自己对第三条做了最严格的限定（"只是这种观察方法可以成立"），但读者应当看清：整套方法的效力，押在治疗师"读得准"这件无法外部校验的事情上。

**边界条件。** 意象解读天然面临"吉田上人问题"——你以为的深奥由来，可能只是孩子调皮放反了石狮子。可贵的是河合隼雄把这个反例亲手写进了书里：他大讲儿童原型，老师一句"这是《杰克和豌豆》"就能让全部解读看似崩塌。他的辩护（故事恰好提供了表达容器、同期其他孩子的选择性模仿、后续画作的发展）是聪明的，但严格说来不可证伪：任何解读失败都可以被"意象的多义性"吸收。现代心理学会追问：沙盘与游戏治疗的疗效证据如何与"共同注意、治疗关系本身"的一般因素剥离？"表面恶化是治疗进步"这类命题如何避免成为不可反驳的万能解释？另外，"超越功能"的退行—创造模型很动人，但"正常范围内的退行"与病态退行的分界，书中只有临床直觉、没有操作标准——这条界线画不准，理论就既能解释创造也能解释崩溃。用它启发观察可以，当诊断依据要慎之又慎。

**跨域映射。** "理念的明确性 vs 原始意象的生命力"，在别的领域反复出现：写作学里是"show, don't tell"——展示（意象）比陈述（概念）更触动人；产品与设计领域，原型（prototype）和 demo 之于需求文档，正是意象之于概念——"一张红桃都没有的牌"胜过十页分析报告；认知科学里，具身认知与心理意象研究同样发现，基于意象的表征比命题表征承载更多情绪与动机信息；"为了自我的退行"在创造力研究中对应"孵化期"（incubation）——搁置问题、任由发散加工运行，然后顿悟；而"象征 = 对立物的更高统合"，黑格尔叫正—反—合，只不过荣格坚持这个"合"不是逻辑推演出来的，是从无意识里长出来的。

**行动触发。** 今天就能做的一件事：下一次你想给别人（或自己）讲道理而对方毫无反应时，停下来，换一个问题——"这件事像什么？"让对方（或自己）给出一个具体的像：一张没有红桃的牌、一座隔开家与蜗牛的山、一根解开的绳子。不解释，不急着翻译成"你的问题是……"。先让意象说完它要说的，再考虑提炼——记住那两个比喻：没有意象浇灌的概念会枯死，不提炼概念的意象是湿木材盖的房子。

## 与全书的连接

在荣格的无意识分层地图上，本章处在"翻译层"：第五章告诉我们原型深藏在集体无意识里、本身不可见；本章回答"那我们看见的是什么"——是意象，原型对意识作用的效果的集约表现；是象征，意象在统合对立物时的创造性升级。往前看，第三章的心理类型（扑克牌之梦的情感机能）、第四章的情结（数学老师像凝聚的父亲情结）、第五章的阴影与太母（表妹、肉的漩涡），在本章全部以意象的形式重新登场——这不是巧合，因为意象正是这些概念在活人心里的存在方式。往后看，河合隼雄已经把路标立好了：意识与无意识交错的地方、意象和象征真正的宝库，是梦。下一章，我们进入夜间剧场，看梦的分析如何运用本章的全部工具——包括那个在游戏里死去又活过来的超人所预告的"死与重生"主题。
