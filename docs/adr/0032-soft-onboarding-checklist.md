# Soft empty-state checklist; no blocking setup wizard

First-run UX is a soft checklist on empty states (add Fish provider connection → create voice → create work). Users can open the work list and edit scripts without configuring TTS first. Synthesis stays disabled until preconditions hold, with copy pointing at Studio Settings.

No blocking onboarding wizard, no account registration, no bundled sample work that requires maintenance. Connecting keys is optional until the user wants audio.
