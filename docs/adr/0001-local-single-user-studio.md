# v1 is a personal local studio, not multi-tenant SaaS

Open Pod is framed as an audiobook/audio-drama production tool with user-configured TTS models. v1 targets a single-user local (or single-instance self-hosted) studio: no multi-tenant isolation, no account/billing system. Collaboration (small-team) and SaaS may come later; do not design the core domain around tenancy.
